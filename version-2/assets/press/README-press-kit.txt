LOGO NOTES
The SVG files embed the supplied high-resolution PNG artwork, so they are ready for web use but are not true vector paths. The editable vector master is cos-logo-master.cdr. If you have CorelDRAW, export a clean SVG from the CDR and replace the SVG files.

TECHNICAL RIDER
The PDF and stage plot are TEMPLATES, not approved technical requirements. Replace every [bracketed] field, confirm the input list, stage dimensions, backline, monitors and hospitality with the band, and approve the final document before sending it to promoters or venues.
