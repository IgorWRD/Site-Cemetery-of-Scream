## 3. Ключові рішення

### 3.1. Біографія: індекс розділів + текстова панель

**Проблема:** суцільний двоколонковий текст біографії важко сканувати; потрібна компактна структура.

**Рішення:** ліворуч — постійний індекс із чотирьох розділів (роки + назва), праворуч — панель, яка змінюється при натисканні. Розділи йдуть хронологічно: 1992—1995, 1995—2000, 2005—2009, 2012—2023. Активний розділ підсвічується бордовим, решта залишаються видимими.

**Чому це працює:**
- структура зрозуміла з першого погляду;
- не треба читати весь архів, щоб знайти потрібний період;
- на десктопі індекс sticky, на мобільному — над панеллю;
- WAI-ARIA tabs: `role="tablist"`, `aria-selected`, `aria-controls`, стрілки/Home/End, roving tabindex;
- без JS усі розділи видимі послідовно, індекс прихований.

### 3.2. Дискографія: master-detail, а не акордеон

**Проблема:** акордеон штовхає весь контент донизу, і список альбомів зникає з поля зору.

**Рішення:** список усіх 8 видань постійно видно ліворуч; він sticky на десктопі. При натисканні змінюється лише права панель: обкладинка, треклист, опис, метадані, посилання. `Oceans` відкритий за замовчуванням. На мобільному список стоїть над панеллю, а після вибору панель підскролюється у видиму область.

**Чому це працює:**
- список завжди перед очима;
- немає стрибків сторінки на десктопі;
- обкладинка й треклист отримують достатньо місця;
- та сама WAI-ARIA-модель, що й у біографії;
- без JS усі панелі видимі послідовно, список прихований.

### 3.3. Галерея: кінематографічна «плівка», не автоплей-карусель

**Рішення:** горизонтальна стрічка кадрів із `scroll-snap`, великими зображеннями, підписами й кредитами; керування стрілками, клавіатурою, drag мишею; прогрес і лічильник. Нижче — архівна сітка змішаних форматів. Будь-який кадр відкривається в `<dialog>`-лайтбоксі з навігацією ←/→, підписом і кредитом.

**Чому не автоплей:**
- WCAG 2.2.2 вимагає можливості зупинити автоперегортання;
- автоплей псує LCP і дратує на мобільних;
- користувач сам керує темпом;
- стрічка працює навіть без JS (нативний горизонтальний скрол).

**Що це дає:** відчуття живої плівки/контактного аркуша, а не слайдера з крапками.

## 5. Технічні рішення

- **Без фреймворків, без збірки.** Чистий HTML/CSS/JS; відкривається з диска або будь-якого статичного хостингу.
- **CSS:** окремі `tokens.css` (дизайн-токени) і `styles.css` (компоненти, секції, адаптив). Один акцент, OKLCH-палітра, fluid type.
- **JS:** ~500 рядків, без залежностей: мобільне меню, scroll spy, reveal, дискографія, галерея, лайтбокс, copy bio, hash-scroll.
- **Доступність:** skip-link, landmarks, один H1, aria-expanded/aria-controls, inert для закритих панелей, клавіатурна навігація стрічки й лайтбокса, focus-visible, reduced motion, контраст.
- **Продуктивність:** self-hosted woff2, preload LCP-зображення й шрифтів, `width`/`height`, lazy loading для галереї, мінімум JS, без сторонніх embed.
- **Зображення:** повні версії для лайтбокса + 720px thumbs для стрічки; загальна вага галереї контрольована.
- **SEO:** унікальні title/description, OG/Twitter, JSON-LD `MusicGroup`, hreflang, `robots.txt`. Canonical і абсолютні OG-URL додати після вибору домену.
- **Аналітика:** не активована, без cookies. Інтеграційна точка — коментар перед `site.js`; покрокова інструкція — `ANALYTICS.md`. Рекомендовано Cloudflare Web Analytics (безкоштовно, без cookies) або Plausible; підключити після домену разом із privacy-сторінкою.
